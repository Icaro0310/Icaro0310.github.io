# Privacy Policy

**gsc-report** is a personal automation tool owned by Icaro Galvao ([@Icaro0310](https://github.com/Icaro0310)). It reads Google Search Console analytics data (clicks, impressions, queries) for the site `icaro0310.github.io`, solely for the owner's own reporting.

- **Data accessed**: read-only Search Console analytics for the owner's own verified site.
- **Data stored**: nothing leaves the owner's machine; no data is shared with third parties.
- **Data deleted**: revoking the OAuth grant at [myaccount.google.com/permissions](https://myaccount.google.com/permissions) removes all access immediately.
